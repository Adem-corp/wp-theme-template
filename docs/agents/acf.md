# ACF: поля

Общие правила проекта — в [AGENTS.md](../../AGENTS.md).

**При создании или изменении групп полей использовать внутренний PHP API ACF с сохранением в БД.** ACFE автоматически
генерирует PHP-файлы групп в `acfe-php/`. Если задача касается только вёрстки, использовать существующую группу без
изменения её полей.

В стартовой теме `acfe-php/` пуст: группы блоков появляются после установки WordPress и ACF/ACFE для конкретного сайта.
Шаблон `layouts/blocks/example/template.php` иллюстрирует поле `heading`, но не означает, что группа уже создана.
Локальная группа настроек форм в `inc/forms/registration.php` — часть базовой темы и исключение из описанного ниже
порядка сохранения проектных групп блоков.

## Сохранение и синхронизация

- Выполнять операции в загруженном окружении WordPress (`wp-load.php`) через PHP CLI или WP-CLI, без браузера и админки.
- Новую группу с вложенными полями сохранять через `acf_import_field_group()`. Для изменений использовать PHP API ACF
	(`acf_update_field()`, `acf_update_field_group()`), сохраняя существующие ключи, поля и настройки.
- Включать PHP-синхронизацию группы: `'acfe' => array( 'autosync' => array( 'php' ) )`. После изменения полей сохранять
	также их группу, чтобы ACFE обработал событие `acf/update_field_group` и сам создал или обновил файл в `acfe-php/`.
- Не ограничиваться `acf_add_local_field_group()`: эта функция регистрирует группу только в PHP и не сохраняет её в БД.
	Не заменять API прямыми SQL-запросами на запись или ручной генерацией PHP-файлов.
- При добавлении layout в `blocks` сохранять clone-поле и настройки Flexible Content через API, затем сохранять группу
	«Контент». Существующие layout'ы и контент страниц должны сохраняться без изменений.
- При сохранении исключать вычисляемые настройки, например URL превью из `acfe/flexible/thumbnail`, чтобы они не
	попадали в БД и экспорт как побочные изменения. Временные фильтры применять только в скрипте операции.
- После операции проверять оба результата: группу и поля в БД (без подмены локальной PHP-регистрацией) и автоматически
	сгенерированный файл ACFE. Проверять diff и PHP-синтаксис; при недоступной БД не подменять результат созданием файла.

## Использование полей в шаблонах

- Источник правды о полях — сгенерированный файл группы `block:{block_name}` в `acfe-php/`. Найти его (например, через
	`git status` / `git diff` или поиск по `'title' => 'block:{block_name}'`) и взять оттуда имена полей, типы,
	вложенные поля и форматы возврата.
- Имена полей в `template.php` должны **точно** совпадать с именами в этом файле. Не придумывать, не переименовывать и
	не добавлять поля.
- Если блок использует `clone` другой группы (например, `title`), при необходимости прочитать и её файл.
- При создании и регистрации нового блока можно читать файлы существующих блоков в `layouts/blocks/` и их группы
	в `acfe-php/`, чтобы сохранить общую структуру и стиль темы. Имена, типы и настройки полей нового блока брать
	из его собственной группы; не копировать поля других блоков без необходимости.
- Если файл группы не найден или структура полей неясна, а создание группы не входит в задачу — уточнить у разработчика.
- Не открывать админку WordPress / интерфейс ACF, не использовать браузер или скриншоты для работы с полями.
- Не создавать и не редактировать файлы в `acfe-php/` вручную: их генерирует ACFE при сохранении групп через API.
- Каждый layout во Flexible Content `blocks` ссылается на отдельную группу полей через `clone` с
	`display => 'seamless'`, без префиксов имени и подписи.

## Вывод значений

- Для полей, в которых выбираются записи CPT (`Relationship`, возврат `Post Object`), выводить записи через `foreach` с
	`setup_postdata( $post )` внутри цикла и `wp_reset_postdata()` после него.
- Изображения приходят как `id`: выводить через `adem_dynamic_thumbnail()` или `wp_get_attachment_image( $id, 'full' )`
	(см. [php.md](php.md)).

## Чего НЕ делать

- Не открывать админку WordPress / интерфейс ACF и не создавать поля через браузер.
- Не создавать и не редактировать файлы в `acfe-php/` вручную; изменения должны генерироваться ACFE из БД через API.
- Не придумывать ACF-поля, которых нет в файле группы блока в `acfe-php/`.
