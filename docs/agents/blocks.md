# Структура блоков

Общие правила проекта — в [AGENTS.md](../../AGENTS.md).

- Каждый блок — отдельная папка: `layouts/blocks/{block_name}/template.php`
- Каждый блок — это `<section>` с классами по БЕМ (`block-name`, `block-name__element`, `block-name--modifier`)
- Блоки подключаются автоматически через `layouts/partials/blocks.php`
- Blocks — это поле Flexible Content с именем `blocks`, в группе полей **«Контент»**
- В стартовой теме группа «Контент» и группы проектных блоков ещё не созданы. Раскладка `example` с полем `heading`
	служит образцом; после установки сайта её поля создают через ACF/ACFE, как описано в [acf.md](acf.md).
- Файл `preview.jpg` (575×250) в папке блока агент не создаёт — его добавляет разработчик.
- Не использовать `<ul>` для формирования разметки блоков: `<ul>` допустим только для текстовых списков. Карточки и
	другие повторяющиеся элементы размещать в обычном контейнере `<div>`.

## Название группы полей блока

- Группа полей, соответствующая layout'у блока, называется по шаблону `block:{block_name}`, например `block:hero`.
- Такая группа полей в админке должна быть **неактивна** (Active — выключено): она подключается только как clone-поле
	внутри layout'а, а не отображается отдельно.
- Если задача включает создание группы или layout, агент создаёт их через PHP API ACF с сохранением в БД и
	автоматической PHP-синхронизацией ACFE. Создание группы само по себе не означает добавление layout в `blocks`.

## Контейнер

- Внутри каждого блока, а также внутри `header` и `footer`, для ограничения ширины контента использовать готовый класс
	`.container` — стили для него уже предусмотрены.
- Не создавать собственный контейнер/обёртку с аналогичной задачей.

## Партиал заголовка

- После создания группы `title` общие ACF-поля заголовка хранятся в ней. В hero и последующих проектных блоках подключать её
	через поле `clone` с `display => 'seamless'`, без префиксов имени и подписи. Группа содержит поле
	`title` с вложенными `text` и `type`; не создавать их заново внутри блоков.

Использовать `layouts/partials/title.php` через:

```php
get_template_part(
	'layouts/partials/title',
	null,
	array(
		'title' => $block_title,
		'class' => 'block-name__title',
	)
);
```

Сигнатура `title.php`:

- `$args['title']` — массив с полями:
	- `'text'` (string)
	- `'type'` (`h1` / `h2` / `h3`)
- `$args['class']` — дополнительный CSS-класс

## Чего НЕ делать

- Не создавать `preview.jpg` и не пытаться его генерировать.
