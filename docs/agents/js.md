# JS

Общие правила проекта — в [AGENTS.md](../../AGENTS.md).

- Alpine.js — для интерактива новых проектных блоков: табы, аккордеоны, тоглы, дропдауны и т.д. Существующий
	`assets/js/main.js` содержит базовую отправку форм и телефонную маску на vanilla JS.
- Для слайдеров/каруселей использовать Carousel или Swiper после выбора и подключения библиотеки в проекте.
- Fancybox (@fancyapps/ui) — для попапов и лайтбоксов после подключения библиотеки в проекте.
- Для Fancybox-ссылок на элемент страницы (`href="#id"`) не задавать явно тип `inline`: достаточно атрибута
	`data-fancybox`.
- Исходный JS собирается существующим Gulp через `npm run build`. Готовые скрипты и стили подключаются через
	`wp_enqueue_scripts` в `inc/theme/assets.php`. Не добавлять webpack или Vite.
