# Работа с Figma

Общие правила проекта — в [AGENTS.md](../../AGENTS.md).

- Если дизайн конкретного блока предоставлен в Figma, перед вёрсткой агент должен изучить его, а не додумывать
	разметку/отступы/цвета самостоятельно. Нейтральный стартовый пример не связан с Figma.
- Для доступа к дизайну использовать Figma MCP-коннектор (если подключён): получать через него структуру блока,
	скриншот, значения переменных (цвета, шрифты, отступы) и метаданные слоёв конкретного фрейма/ссылки, которую передал
	разработчик.
- Работать только с тем фреймом, ссылку на который передал разработчик. Не загружать целую страницу или весь файл.
- Значения цветов и шрифтов, полученные из Figma-переменных, сопоставлять с уже существующими переменными в
	`_variables.scss` (см. [css.md](css.md), раздел «Переменные»), а не заводить новые дублирующие значения.
- Если задача требует соответствия конкретному макету, но ссылка на фрейм/страницу Figma не передана — уточнить её у
	разработчика, а не искать нужный блок в файле самостоятельно.
- Значения из дизайна (отступы, размеры, шрифты) не переносить один в один "как есть" — округлять до аккуратных чисел
	(например, до чётных или кратных 4/8), так как в самом дизайне значения могут быть неточными.

## Чего НЕ делать

- Не переносить значения из Figma "как есть" без округления — точные пиксельные значения из дизайна могут быть
	неточными.
