# Стартовая тема WordPress

Классическая тема с префиксом PHP-функций `adem_`. Для Flexible Content нужны ACF Pro и, для миниатюр раскладок, ACF Extended. Без ACF тема загружается, но настройки форм и блоки недоступны.

## Структура

- `functions.php` задаёт версию и подключает `inc/bootstrap.php`.
- `inc/theme/` содержит поддержку темы, ресурсы, фильтры и общие хелперы.
- `inc/forms/` содержит тип записей заявок `mail`, настройки ACF, AJAX-обработчик, защиту от спама и учёт первого источника.
- `inc/integrations/` содержит ACF/ACFE, REST, SVG и TinyMCE.
- `layouts/partials/blocks.php` выводит раскладки из `layouts/blocks/<имя>/template.php`.
- `assets/scss/` и `assets/js/` содержат исходники и результат сборки.

## Формы

В ACF появится страница **Формы**. Добавьте получателей в повторитель «Адреса для отправки почты», при необходимости отметьте «Нужен ли трафик в письме» и укажите почту отправителя. Если получатели не заданы, заявка сохраняется, но письмо не отправляется.

Форма должна иметь класс `js-form`, непустой атрибут `name`, кнопку отправки и скрытое поле nonce с именем `nonce`. Значение nonce создаётся для действия, равного атрибуту `name`:

```php
<form class="js-form" name="contact" method="post" enctype="multipart/form-data">
    <?php adem_wp_nonce_field( 'contact', 'nonce', true ); ?>
    <input name="name" required>
    <input name="email" type="email">
    <input name="files[]" type="file" multiple>
    <button type="submit">Отправить</button>
</form>
```

JS отправляет `action=send_mail`, `form_name`, `time_on_page` и `typing_speed` в `admin-ajax.php`. Обработчик проверяет nonce и оценивает время на странице и интервалы печати по балльной антиспам-проверке, затем сохраняет все непустые текстовые поля в заявку `mail` и прикрепляет загруженные файлы к ней. Антиспам пишет журнал с данными отправки в `WP_CONTENT_DIR/antibot.log`. Ссылки на файлы остаются в заявке; сами файлы передаются в `wp_mail` как вложения. Для ответа используются события `adem:form-success` и `adem:form-error` на форме. При наличии `#modal-success` и Fancybox открывается окно успеха.

На первом посещении `inc/forms/traffic.php` берёт UTM-метки или внешний referrer, а при их отсутствии записывает прямой переход. Источник хранится месяц в `source_cookie` и `traffic_source`; последующие переходы его не заменяют. Источник сохраняется в заявке и по выбору получателя добавляется в письмо. AJAX, REST, cron и админские запросы новые cookies не устанавливают.

## REST API

Анонимному посетителю по умолчанию не разрешено ни одно пространство имён REST. Для конкретного проекта добавьте исключения через фильтр, например:

```php
add_filter( 'adem_allowed_rest_namespaces', function ( $namespaces ) {
    $namespaces[] = '/example/v1';
    return $namespaces;
} );
```

Индекс REST показывает только разрешённые маршруты; обращение к остальным возвращает 401. У вошедших пользователей маршруты не фильтруются. Указывайте пространство имён целиком, а не отдельный URL.

## Flexible Content

После установки WordPress, ACF Pro и ACFE создайте в БД группу «Контент» с полем Flexible Content `blocks`. Внутри добавьте раскладку `example` с текстовым полем `heading`. Группы создавайте через PHP API ACF с автосинхронизацией ACFE, как описано в `docs/agents/acf.md`; тема сама поля блока не регистрирует. Это нейтральный пример из `layouts/blocks/example/`: его `template.php` выводит заголовок, а `preview.jpg` служит миниатюрой в ACFE. Для нового блока создайте каталог с именем раскладки и файлом `template.php`; миниатюра `preview.jpg` необязательна. Шаблон каждого блока получает `$args['block_id']` — уникальную строку для группы Fancybox или HTML ID; при выводе в атрибут используйте `esc_attr()`.

## Сборка

```bash
npm install
npm run build
```

Gulp собирает `assets/scss/style.scss` в корневой `style.css` и `assets/js/main.js` в `assets/js/main.min.js`. Сторонние библиотеки в тему не входят и не подключаются автоматически. Для конкретного проекта установите нужные версии и добавьте их подключение в `inc/theme/assets.php`. При отсутствии Fancybox отправка формы работает, но окно успеха не открывается; вместо него можно обработать событие `adem:form-success`. Для разработки передайте адрес уже работающего локального WordPress-сайта: `WP_PROXY=http://my-site.test npm run dev`. Gulp не определяет его автоматически; без `WP_PROXY` задача остановится с ошибкой. В `assets/scss/base/_font-face.scss` оставлен пример `@font-face`: замените `FontName` и пути к файлам при добавлении шрифтов. Пока тема использует системный Arial.
