# AGENTS.md

Инструкции для AI-агентов (Claude Code, Cursor, Codex и т.д.), работающих с этим репозиторием.
Это стартовая классическая WordPress-тема **без Gutenberg**. Контент управляется через ACF + ACF Extended (ACFE).
Группы полей проектных блоков и дизайн Figma появляются при настройке конкретного сайта; нейтральный блок `example`
оставлен как образец и не регистрирует поля автоматически.

---

## Порядок работы над блоком

1. Если для блока предоставлен дизайн Figma, получить его (см. [figma.md](docs/agents/figma.md)).
2. Найти и прочитать файл группы полей блока в `acfe-php/`. Если задача включает создание группы, сначала сохранить её
	через PHP API ACF и дождаться генерации файла ACFE (см. [acf.md](docs/agents/acf.md)).
3. Написать `layouts/blocks/{block_name}/template.php`, используя **только** поля из этого файла.
4. Написать SCSS блока и, при необходимости, JS (Alpine.js / Carousel / Fancybox).
5. Запустить PHPCBF для изменённых PHP-файлов, затем проверить их через PHPCS по WordPress Coding Standards (WPCS)
	и исправить оставшиеся ошибки. Конфигурация `phpcs.xml.dist` проверяет код темы.
6. Проверить изменённые SCSS-файлы через Stylelint с конфигурацией `.stylelintrc.json` и исправить найденные ошибки.
7. После изменений SCSS или JS запустить `npm run build` и проверить собранные файлы.

Итогового отчёта не нужно: достаточно короткого сообщения о том, что сделано.

---

## Стек

- WordPress (кастомная тема, без Gutenberg / block editor)
- PHP: ACF + ACF Extended (ACFE)
- JS: Alpine.js для новых интерактивных блоков; Carousel, Swiper и Fancybox подключаются при необходимости в конкретном проекте.
- SCSS и JS собираются существующим Gulp (`gulpfile.js`, `npm run build`); готовые файлы подключаются через `wp_enqueue_scripts` в `inc/theme/assets.php`.
- CSS: SCSS, методология BEM, линтинг через собственный `.stylelintrc.json`

## Чего НЕ делать (общее)

- Не использовать блоки/паттерны Gutenberg.
- Не добавлять webpack, Vite или другой параллельный сборщик. Развивать существующую конфигурацию Gulp.

Остальные запреты — в файлах соответствующих зон.
